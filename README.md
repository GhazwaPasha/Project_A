## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- Windows 10/11 (recommended for optimal Mica effects)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/Project_A.git
   cd Project_A
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python main.py
   ```
